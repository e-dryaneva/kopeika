# Копейка

Учёт доходов и расходов. Запись — через Быструю команду на Кнопке действия,
без открытия чего-либо. Просмотр — веб-страница, которую можно положить на домашний экран.

Один Cloudflare Worker отдаёт и API, и саму страницу. База — D1 (SQLite).
Всё помещается в бесплатный тариф.

## Что где

| Файл | Зачем |
|---|---|
| `src/index.js` | API и роутинг |
| `src/page.html` | разметка и стили трёх экранов |
| `src/app.script.html` | вся клиентская логика (вклеивается в страницу воркером) |
| `src/parse.js` | разбор текста вида «500 такси домой», палитра цветов |
| `schema.sql` | таблицы операций, категорий и настроек |
| `wrangler.jsonc` | конфиг воркера, часовой пояс |
| `design/tracker.dc.html` | исходный макет, распакованный из канваса |

Экраны: **Операции** (список с фильтрами), **Запись** (нумпад) и **Обзор**
(лимит, расходы по дням и по категориям). Тема тёмная, переключается на светлую
кнопкой в «Обзоре».

## Как выложить

Один раз, с этого мака. Нужен бесплатный аккаунт Cloudflare.

```bash
cd ~/Projects/kopeika-web && npm install
```

```bash
npx wrangler login
```

Создать базу и вписать её id в `wrangler.jsonc` вместо нулей в поле `database_id`:

```bash
npx wrangler d1 create kopeika
```

Создать таблицу:

```bash
npm run db:init
```

Придумать токен доступа (сохрани его — он понадобится и команде, и странице):

```bash
openssl rand -base64 24
```

Положить токен в секреты воркера — вставить его в ответ на приглашение:

```bash
npx wrangler secret put API_TOKEN
```

Выложить:

```bash
npm run deploy
```

В конце wrangler напечатает адрес вида `https://kopeika.<твоё-имя>.workers.dev`.

## Быстрая команда на Кнопку действия

В приложении «Быстрые команды» → новая команда из четырёх действий:

1. **Запросить ввод** — тип «Текст», вопрос «Трата?»
2. **Загрузить содержимое URL**
   - URL: `https://kopeika.<твоё-имя>.workers.dev/api/entry`
   - Способ: `POST`
   - Заголовки: `Authorization` → `Bearer ТВОЙ_ТОКЕН`
   - Тело запроса: `JSON`, поле `text` (текст) → значение «Предоставленный ввод»
3. **Получить значение словаря** — ключ `message`
4. **Показать уведомление** — со значением из шага 3

Назвать «Записать», затем: Настройки → Кнопка действия → Быстрая команда → «Записать».

Дальше нажатие кнопки спрашивает строку и молча отправляет её. Приложение не открывается.

### Что можно писать

```
500 еда              расход 500 ₽, категория «Еда»
1 200,50 такси домой расход с заметкой «домой»
+80000 зарплата      доход
300                  расход 300 ₽ в «Прочее»
```

Категория узнаётся по слову: `еда, продукты, кафе, кофе, такси, метро, бензин,
аренда, жкх, аптека, кино, подписка, одежда, зарплата, подработка, подарок…`
Полный список синонимов — в `src/categories.js`, дописывать можно свободно.

### Вариант без клавиатуры

Если не хочется печатать категорию, вместо шага 1 поставь **Выбрать из меню** с
пунктами по категориям, а в теле запроса отправляй два поля: `amount` (число из
«Запросить ввод») и `category` — название категории ровно как в приложении,
например `Кафе` или `Транспорт`.

## Приложение

Открыть адрес воркера в Safari, ввести тот же токен — он сохранится в браузере.
Поделиться → «На экран "Домой"», чтобы страница открывалась без адресной строки.

### Правка операций

Тап по строке в «Операциях» поднимает шторку с той же раскладкой, что и экран
записи: переключатель расход/доход, крупная сумма, нумпад, категории, заметка и
дата. Снизу «Сохранить», под ней «Удалить», в шапке справа «Закрыть».
Шторка помещается целиком без прокрутки, на невысоких экранах ужимается.

Смена категории на доходную меняет и знак операции. Смена даты может перенести
операцию в другой месяц — тогда из текущего списка она исчезнет.

### Категории

Меняются прямо в приложении: экран «Запись» → чип **＋ Категория**. Там можно
переименовать, удалить и сменить цвет тапом по квадрату. Эмодзи задаётся первым
символом названия — например `🐈 Кот`. Удаление категории не трогает уже
записанные операции: в них лежит снимок названия, эмодзи и цвета.

Новые категории сразу узнаются в быстрой команде по названию: создала «Кот» —
можно писать `1500 кот корм`.

### Лимиты

Шторка **Лимиты** открывается четырьмя способами: кнопка с ползунками в шапке
«Обзора», тап по карточке лимита, тап по любой строке в «По категориям» и тап по
остатку сверху на экране записи. Внутри сверху общий лимит на месяц, ниже — лимит
на каждую категорию расходов. Суммы в рублях, пустое поле или ноль означают «без
лимита». Сохраняются по уходу из поля.

От общего лимита считаются остаток, полоса прогресса и строчка «выше/ниже
графика». Остаток показывается сверху на экране записи и уходит в уведомление
быстрой команды.

В «Обзоре» две карточки: «Потрачено в августе» с суммой и под ней компактная
карточка лимита — сам лимит, полоса и строка «Осталось 13 011 ₽ · выше графика на
5 376 ₽».

В карточке «По категориям» сверху справа сумма расходов, под ней полоса выборки
лимита и остаток: «осталось 2 750 ₽», при превышении — красное «превышен на
12 280 ₽». Если лимита нет, под строкой не рисуется ничего. Категория с лимитом
видна в списке, даже если трат по ней ещё не было.

Все полосы прогресса одного синего цвета, включая превышенные лимиты, — про
превышение говорит только текст.

## Часовой пояс

`TZ_OFFSET_MINUTES` в `wrangler.jsonc` — сейчас `180` (Москва). По нему операции
раскладываются по месяцам. Поменяешь пояс — поменяй и здесь.

## Проверки

```bash
npm test
```

55 проверок API на встроенном в Node SQLite — разбор текста, копейки, лимиты
общий и по категориям, правка и удаление операций, редактирование категорий,
фильтры по месяцам. Сеть и wrangler не нужны.

## Локальный просмотр

```bash
npm run dev
```

Нужен файл `.dev.vars` рядом с `wrangler.jsonc` со строкой `API_TOKEN=любой-токен`.
